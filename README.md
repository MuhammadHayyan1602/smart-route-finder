🧭 Smart Route Finder using BFS, DFS & UCS
AI-based route finder using BFS, DFS and UCS with map visualization

📌 Project Description
This project finds the best route between cities using graph search algorithms:
- BFS (Breadth First Search)
- DFS (Depth First Search)
- UCS (Uniform Cost Search)

It also includes:
- Interactive UI using ipywidgets
- Map visualization using Folium
- Real-time travel simulation

🧠 Algorithms Used
- BFS → Shortest hops
- DFS → Deep traversal
- UCS → Optimal path (minimum cost)

🗺️ Features
- City-to-city route finding
- Cost and time calculation
- Animated map route
- Step-by-step travel simulation

 ⚙️ Tech Stack
- Python
- Pandas
- Folium
- ipywidgets

🚀 How to Run
1. Open notebook in Google Colab
2. Run all cells
3. Select start and destination city
4. Click "Find Route"
